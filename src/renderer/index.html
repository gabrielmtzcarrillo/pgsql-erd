    Import tables from Excel / CSV
    
      
    Each sheet becomes a table. A sheet whose first row has Column and Type headers
        (optionally Table, Length, Scale, Nullable, PK, Unique, Default, References, Comment) is read as column
        definitions, one row per column. Any other sheet is read as data: the first row names the columns and their types
        are inferred from the values. Tables already in the diagram are updated; their position, color and note are kept.
